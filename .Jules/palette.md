## 2024-06-25 - Authentication Required Field Indicators
**Learning:** Adding explicit required field indicators (red asterisks) to forms, especially those critical like login and register, improves visual clarity and reduces friction. However, explicitly adding `aria-required="true"` to elements that already have the HTML5 `required` attribute is redundant for modern screen readers, though harmless.
**Action:** In future form improvements, rely on the HTML5 `required` attribute for screen reader accessibility and only add visual indicators (like `aria-hidden="true"` asterisks) without duplicating the ARIA state attribute.
