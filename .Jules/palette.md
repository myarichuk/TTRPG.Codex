## 2025-07-02 - Added accessibility metadata to forms
**Learning:** Found multiple instances where required text inputs lacked visually-distinct, programmatically-accessible required markers (like `*` and `aria-required`), and search inputs lacked explicit `aria-label` attributes for screen readers. Form accessibility needs to explicitly tie visual cues with ARIA attributes.
**Action:** Always append `<span class="text-danger" aria-hidden="true">*</span>` to labels and add `aria-required="true"` to required form inputs to ensure both visual styling and screen reader consistency. Ensure all icon-only or generic inputs (like a search bar) have descriptive `aria-label`s.
