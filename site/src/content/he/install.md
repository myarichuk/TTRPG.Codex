TTRPG.Codex רץ **על המחשב שלכם**, מחשבו של שליט המבוך. השחקנים פותחים אותו בדפדפן רגיל, ולכן אין להם שום דבר להתקין. כל מה שלהלן לוקח כחמש דקות.

## בוחרים הורדה {#download}

פותחים את [הגרסה האחרונה](https://github.com/myarichuk/TTRPG.Codex/releases/latest) ובוחרים את הקובץ המתאים למערכת. כל חבילה כבר כוללת את סביבת ההרצה של .NET שהיא צריכה.

| מערכת | מתקין | נייד |
| --- | --- | --- |
| Windows (x64) | `TTRPG.Codex-<version>-win-x64-setup.exe`, מותקן למשתמש שלכם, בלי הרשאות מנהל | `.zip` |
| macOS (Apple silicon) | `.pkg`, מותקן בתיקיית היישומים | `.tar.gz` |
| Linux (x64) | `.deb` (Debian, Ubuntu וקרובותיהן) | `.tar.gz` |

אם אתם לא בטוחים, בחרו במתקין.

> [!NOTE]
> החבילות עדיין לא חתומות דיגיטלית, ולכן Windows ו-macOS יבקשו אישור בפעם הראשונה. להלן מוסבר היכן ללחוץ.

## Windows {#windows}

1. מריצים את `TTRPG.Codex-<version>-win-x64-setup.exe`.
2. אם מופיע החלון **״Windows הגן על המחשב שלך״**, בוחרים **״מידע נוסף״** ואז **״הפעל בכל זאת״**.
3. מסיימים את ההתקנה ומפעילים את **TTRPG.Codex** מתפריט התחל.

מעדיפים בלי מתקין? מחלצים את ה-`.zip` לכל מקום ומריצים את `launcher\ttrpg-codex-tray.exe`.

## macOS {#macos}

1. פותחים את קובץ ה-`.pkg`. אם macOS מסרבת מפני שהמפתח אינו מזוהה, **לוחצים על הקובץ לחיצה ימנית ובוחרים ״פתח״** ומאשרים.
2. מפעילים את **TTRPG.Codex** מתיקיית היישומים. הסמל שלו יופיע בשורת התפריטים.

מעדיפים בלי מתקין? מחלצים את ה-`.tar.gz` ומריצים את `launcher/ttrpg-codex-tray`.

## Linux {#linux}

מתקינים את החבילה ואז מפעילים את **TTRPG.Codex** מתפריט היישומים:

```sh
sudo apt install ./ttrpg-codex_<version>_amd64.deb
```

היישום נמצא ב-`/opt/ttrpg-codex`, והפקודה `ttrpg-codex` נוספת ל-PATH. מעדיפים ארכיון רגיל? מחלצים את ה-`.tar.gz` ומריצים את `launcher/ttrpg-codex-tray`.

> [!TIP]
> GNOME אינה מציגה סמלים במגש המערכת אלא אם הותקנה הרחבת AppIndicator. גם בלעדיה המפעיל עובד: יש לו חלון רגיל, שמצטמצם במקום להיעלם.

## הפעלה ראשונה {#first-run}

ההפעלה הראשונה לוקחת קצת יותר זמן, כי מסד הנתונים מוכן. אחר כך:

1. חלון קבלת פנים שואל מי ישחק. בוחרים ״[[ui:Launcher.Welcome.HostTitle]]״ כדי לאפשר לשחקנים ברשת ה-Wi-Fi שלכם להצטרף, או ״[[ui:Launcher.Welcome.SoloTitle]]״ כדי להישאר בינתיים במחשב הזה. אפשר לשנות את זה בכל רגע.
2. הדפדפן נפתח באפליקציה בכתובת `http://localhost:5080`.
3. פותחים חשבון. **החשבון הראשון הופך למנהל השרת.**
4. לוחצים על ״[[ui:Page.Home.New]]״, נותנים שם לקמפיין ובוחרים מערכת משחק.

מעכשיו TTRPG.Codex יושב במגש המערכת (בשורת התפריטים ב-macOS). התפריט שלו מפעיל ועוצר את השרת, מעתיק את הקישור לשחקנים ופותח את היומן. סגירת חלון המפעיל **אינה** עוצרת את המשחק; לשם כך יש את ״[[ui:Launcher.Quit]]״.

## מאפשרים לשחקנים להצטרף {#players}

המחשב שלכם אינו מחובר ישירות לאינטרנט, ולכן שחקנים זקוקים לקישור שמגיע אליו.

### באותו חדר או באותה רשת Wi-Fi {#wifi}

1. במפעיל, מדליקים את ״[[ui:Launcher.Lan.Toggle]]״. חומת האש עשויה לשאול פעם אחת: מתירים **רשתות פרטיות**.
2. לוחצים על ״[[ui:Launcher.QrCode]]״ והשחקנים סורקים אותו במצלמת הטלפון, או לוחצים על ״[[ui:Launcher.CopyLink]]״ ושולחים להם את הקישור.
3. בקמפיין, מעתיקים את **קישור ההזמנה** מעמוד הסקירה ושולחים גם אותו. השחקנים פותחים חשבון, והם בפנים.

שומרים על המחשב ער ומחובר לחשמל בזמן המשחק: אם הוא נרדם, כולם מתנתקים.

### שחקנים במקום אחר {#remote}

שחקנים מחוץ לרשת שלכם זקוקים לדרך פרטית אל המחשב. הדרך החינמית הקלה ביותר היא [Tailscale](https://tailscale.com):

1. אתם וכל שחקן מתקינים את Tailscale ומתחברים.
2. ב-Tailscale משתפים את המחשב שלכם עם כל שחקן.
3. מדליקים את ״[[ui:Launcher.Lan.Toggle]]״. מופיע קישור בשם ״[[ui:Launcher.Link.Tailscale]]״. שולחים אותו לשחקנים; הם פותחים אותו בדפדפן כש-Tailscale פועל.

> [!WARNING]
> אל תפתחו פורט בנתב כדי לחשוף את TTRPG.Codex לאינטרנט הפתוח. התוכנה בנויה לשולחן פרטי, לא לאירוח ציבורי.

### אם שחקן לא מצליח להתחבר {#cant-join}

לוחצים על ״[[ui:Launcher.CantJoin]]״ במפעיל. הוא בודק את השרת, את הרשת ואת הכתובת, ואומר מה לתקן, החל בפריט האדום הראשון. הסיבות הרגילות:

- חומת האש חסמה. מתירים ל-TTRPG.Codex לעבוד ברשתות פרטיות או ביתיות.
- רשת Wi-Fi לאורחים או בבית קפה מונעת לעיתים קרובות ממכשירים לראות זה את זה. משתמשים ברשת הרגילה, או ב-Tailscale.
- כתובת המחשב השתנתה אחרי הפעלה מחדש או רשת חדשה. מעתיקים את הקישור החדש מהמפעיל ושולחים שוב.
- הגישה מהרשת הודלקה אחרי שהשרת כבר התחיל. עוצרים את השרת ומפעילים מחדש.

## מתקינים בטלפון {#phone}

אפליקציית הרשת ניתנת להתקנה, כך ששחקן יכול להחזיק אותה במסך הבית כמו כל אפליקציה אחרת.

1. פותחים את הקישור ב-Safari (iPhone ו-iPad) או ב-Chrome (Android).
2. בוחרים **״הוסף למסך הבית״**.

מאותו רגע היא נפתחת במסך מלא עם סמל משלה. השולחן החי זקוק לחיבור למחשב שלכם; בלי רשת מקבלים עמוד פשוט של ״אין חיבור״ במקום נתונים מיושנים.

## הנתונים שלכם, גיבויים ועדכונים {#data}

הקמפיינים נשמרים במסד נתונים בתיקיית המשתמש שלכם, לא בתיקיית התוכנה, ולכן **עדכון או התקנה מחדש אינם נוגעים בהם**.

| מערכת | תיקיית נתונים |
| --- | --- |
| Windows | `%LOCALAPPDATA%\TTRPG.Codex` |
| macOS | `~/Library/Application Support/TTRPG.Codex` |
| Linux | `~/.local/share/ttrpg-codex` |

תפריט המפעיל פותח את התיקיות האלה בשבילכם: ״[[ui:Launcher.Tray.Data]]״, ״[[ui:Launcher.Tray.ContentFolder]]״ ו-״[[ui:Launcher.Tray.BackupsFolder]]״. מערכות משחק וחבילות תוכן משלכם הולכות לתיקיית `content` שבתוך תיקיית הנתונים.

> [!WARNING]
> הרישיון החינמי של מסד הנתונים המשובץ אינו מתיר את הגיבויים המתוזמנים המובנים שלו, ולכן אל תסתמכו על תיקיית Backups. השתמשו ב״[[ui:Campaign.Settings.Export]]״ בהגדרות כל קמפיין: הוא מוריד את הקמפיין כולו (דמויות, מפגשים, אגדות עולם, הערות ותוכן ביתי) כקובץ אחד, ו״[[ui:Campaign.Settings.Import]]״ משחזר אותו.

כדי לעדכן, מתקינים את החבילה החדשה מעל הישנה. כדי להסיר, משתמשים ב״אפליקציות ותכונות״ ב-Windows, מוחקים את היישום מתיקיית היישומים ב-macOS, או מריצים `sudo apt remove ttrpg-codex` ב-Linux. הקמפיינים נשארים בתיקיית הנתונים עד שתמחקו אותה בעצמכם.

## מריצים מקוד המקור {#source}

צריך את [.NET 10 SDK](https://dotnet.microsoft.com/download).

```sh
git clone https://github.com/myarichuk/TTRPG.Codex.git
cd TTRPG.Codex
dotnet run --project src/Codex.Web
```

פותחים את `http://localhost:5183`, יוצרים חשבון וקמפיין, ושולחים את קישור ההזמנה. הנתונים נמצאים ב-RavenDB משובץ תחת `src/Codex.Web/RavenData`; משנים זאת בהגדרה `Codex:DataDirectory`. התוכן נטען מהתיקיות שב-`Codex:ContentDirectories` בקובץ `appsettings.json`. את הבדיקות מריצים בפקודה `dotnet test`.

כדי לאפשר לשחקנים ברשת שלכם להצטרף להרצה מקוד המקור, מאזינים לכל הכתובות:

```sh
ASPNETCORE_URLS=http://0.0.0.0:5183 dotnet run --project src/Codex.Web
```

## פתרון בעיות {#troubleshooting}

**הדפדפן לא נפתח.** פותחים בעצמכם את `http://localhost:5080`, או בוחרים ״[[ui:Launcher.Tray.Open]]״ מתפריט המגש.

**השרת לא עלה.** ייתכן שתוכנה אחרת משתמשת בפורט 5080, לרוב עותק שני של TTRPG.Codex. סוגרים אותה ומפעילים מחדש. היומן של המפעיל (״[[ui:Launcher.Tray.Log]]״) מראה את הפרטים; שלחו אותו למי שעוזר לכם.

**ההפעלה הראשונה איטית.** זה תקין. הפעלות הבאות מהירות.

**אחרי עדכון משהו נראה מוזר.** מרעננים את העמוד ללא מטמון (Ctrl+F5, או Cmd+Shift+R ב-Mac).

עדיין תקועים? [פותחים issue](https://github.com/myarichuk/TTRPG.Codex/issues) ומצרפים את היומן.
