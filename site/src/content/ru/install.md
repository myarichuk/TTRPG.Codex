TTRPG.Codex работает **на вашем компьютере**, компьютере Мастера. Игроки открывают его в обычном браузере, так что им ничего устанавливать не нужно. Всё ниже займёт около пяти минут.

## Выберите, что скачать {#download}

Откройте [последний выпуск](https://github.com/myarichuk/TTRPG.Codex/releases/latest) и выберите файл для своей системы. В каждый пакет уже входит нужная среда выполнения .NET.

| Система | Установщик | Переносная версия |
| --- | --- | --- |
| Windows (x64) | `TTRPG.Codex-<версия>-win-x64-setup.exe`, ставится для вашего пользователя, права администратора не нужны | `.zip` |
| macOS (Apple silicon) | `.pkg`, ставится в «Программы» | `.tar.gz` |
| Linux (x64) | `.deb` (Debian, Ubuntu и родственные) | `.tar.gz` |

Если не уверены, берите установщик.

> [!NOTE]
> Пакеты пока не подписаны цифровой подписью, поэтому при первом запуске Windows и macOS попросят подтверждение. Ниже показано, куда нажимать.

## Windows {#windows}

1. Запустите `TTRPG.Codex-<версия>-win-x64-setup.exe`.
2. Если появилось окно **«Система Windows защитила ваш компьютер»**, нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.
3. Завершите установку и запустите **TTRPG.Codex** из меню «Пуск».

Не хотите установщик? Распакуйте `.zip` куда угодно и запустите `launcher\ttrpg-codex-tray.exe`.

## macOS {#macos}

1. Откройте `.pkg`. Если macOS отказывается, потому что разработчик неизвестен, **щёлкните файл правой кнопкой и выберите «Открыть»**, затем подтвердите.
2. Запустите **TTRPG.Codex** из папки «Программы». Его значок появится в строке меню.

Не хотите установщик? Распакуйте `.tar.gz` и запустите `launcher/ttrpg-codex-tray`.

## Linux {#linux}

Установите пакет, затем запустите **TTRPG.Codex** из меню приложений:

```sh
sudo apt install ./ttrpg-codex_<версия>_amd64.deb
```

Приложение лежит в `/opt/ttrpg-codex`, а в PATH добавляется команда `ttrpg-codex`. Предпочитаете обычный архив? Распакуйте `.tar.gz` и запустите `launcher/ttrpg-codex-tray`.

> [!TIP]
> GNOME не показывает значки в области уведомлений, пока не установлено расширение AppIndicator. Без него программа запуска всё равно работает: у неё обычное окно, которое сворачивается, а не прячется.

## Первый запуск {#first-run}

Первый запуск занимает чуть больше времени: готовится база данных. Дальше:

1. Окно приветствия спросит, кто будет играть. Выберите «[[ui:Launcher.Welcome.HostTitle]]», чтобы пускать игроков из вашей сети Wi-Fi, или «[[ui:Launcher.Welcome.SoloTitle]]», чтобы пока ограничиться этим компьютером. Это можно изменить в любой момент.
2. Браузер откроет приложение по адресу `http://localhost:5080`.
3. Создайте учётную запись. **Первая учётная запись становится администратором сервера.**
4. Нажмите [[ui:Page.Home.New]], назовите кампанию и выберите игровую систему.

Теперь TTRPG.Codex живёт в области уведомлений (в строке меню на macOS). Через его меню можно запускать и останавливать сервер, копировать ссылку для игроков и открывать журнал. Закрытие окна программы запуска **не** останавливает игру; для этого есть пункт «[[ui:Launcher.Quit]]».

## Как пустить игроков {#players}

Ваш компьютер не подключён к интернету напрямую, поэтому игрокам нужна ссылка, которая до него дотянется.

### В одной комнате или в одной сети Wi-Fi {#wifi}

1. В программе запуска включите «[[ui:Launcher.Lan.Toggle]]». Брандмауэр может один раз спросить: разрешите **частные сети**.
2. Нажмите «[[ui:Launcher.QrCode]]», и игроки смогут отсканировать код камерой телефона, либо нажмите «[[ui:Launcher.CopyLink]]» и отправьте им ссылку.
3. В кампании скопируйте **ссылку-приглашение** на странице «Обзор» и тоже отправьте её. Игроки создают учётную запись, и они в игре.

Не давайте компьютеру уснуть и держите его включённым в розетку во время игры: если он уснёт, все будут отключены.

### Игроки в другом месте {#remote}

Игрокам вне вашей сети нужен закрытый путь к вашему компьютеру. Самый простой бесплатный — [Tailscale](https://tailscale.com):

1. Вы и каждый игрок устанавливаете Tailscale и входите в учётную запись.
2. В Tailscale откройте доступ к своему компьютеру каждому игроку.
3. Включите «[[ui:Launcher.Lan.Toggle]]». Появится ссылка с подписью «[[ui:Launcher.Link.Tailscale]]». Отправьте её игрокам: они открывают её в браузере при включённом Tailscale.

> [!WARNING]
> Не пробрасывайте порт на роутере, чтобы выставить TTRPG.Codex в открытый интернет. Программа рассчитана на закрытый стол, а не на публичный хостинг.

### Если игрок не может подключиться {#cant-join}

Нажмите «[[ui:Launcher.CantJoin]]» в программе запуска. Она проверит сервер, сеть и адрес и подскажет, что исправить, начиная с первого красного пункта. Обычные причины:

- Брандмауэр заблокировал соединение. Разрешите TTRPG.Codex в частных или домашних сетях.
- Гостевой Wi-Fi или Wi-Fi кафе часто не даёт устройствам видеть друг друга. Используйте обычный Wi-Fi или Tailscale.
- Адрес компьютера изменился после перезапуска или подключения к другой сети. Скопируйте новую ссылку из программы запуска и отправьте заново.
- Доступ из сети включили уже после запуска сервера. Остановите сервер и запустите снова.

## Установка на телефон {#phone}

Веб-приложение можно установить, так что игрок может держать его на экране «Домой», как любое другое приложение.

1. Откройте ссылку в Safari (iPhone и iPad) или Chrome (Android).
2. Выберите **«На экран „Домой“»** (в Chrome — «Добавить на главный экран»).

После этого оно открывается на весь экран со своим значком. Живому столу нужна связь с вашим компьютером; без сети вместо устаревших данных вы увидите простую страницу «вы не в сети».

## Ваши данные, резервные копии и обновления {#data}

Кампании хранятся в базе данных в папке вашего пользователя, а не в папке программы, поэтому **обновление и переустановка их не затрагивают**.

| Система | Папка с данными |
| --- | --- |
| Windows | `%LOCALAPPDATA%\TTRPG.Codex` |
| macOS | `~/Library/Application Support/TTRPG.Codex` |
| Linux | `~/.local/share/ttrpg-codex` |

Меню программы запуска открывает эти папки за вас: «[[ui:Launcher.Tray.Data]]», «[[ui:Launcher.Tray.ContentFolder]]» и «[[ui:Launcher.Tray.BackupsFolder]]». Ваши игровые системы и наборы материалов кладите в папку `content` внутри папки с данными.

> [!WARNING]
> Бесплатная лицензия встроенной базы данных не разрешает её собственные резервные копии по расписанию, поэтому не полагайтесь на папку Backups. Используйте «[[ui:Campaign.Settings.Export]]» в настройках каждой кампании: она скачивает всю кампанию (персонажей, сессии, предания, заметки и собственный материал) одним файлом, а «[[ui:Campaign.Settings.Import]]» восстанавливает её.

Чтобы обновиться, установите новый пакет поверх старого. Чтобы удалить программу, воспользуйтесь «Приложения и возможности» в Windows, удалите её из «Программ» в macOS или выполните `sudo apt remove ttrpg-codex` в Linux. Ваши кампании остаются в папке с данными, пока вы сами её не удалите.

## Запуск из исходного кода {#source}

Вам понадобится [.NET 10 SDK](https://dotnet.microsoft.com/download).

```sh
git clone https://github.com/myarichuk/TTRPG.Codex.git
cd TTRPG.Codex
dotnet run --project src/Codex.Web
```

Откройте `http://localhost:5183`, создайте учётную запись и кампанию и отправьте ссылку-приглашение. Данные лежат во встроенной базе RavenDB в `src/Codex.Web/RavenData`; путь меняется параметром `Codex:DataDirectory`. Материалы загружаются из папок, перечисленных в `Codex:ContentDirectories` в `appsettings.json`. Тесты запускаются командой `dotnet test`.

Чтобы пустить игроков из вашей сети при запуске из исходного кода, привяжитесь ко всем адресам:

```sh
ASPNETCORE_URLS=http://0.0.0.0:5183 dotnet run --project src/Codex.Web
```

## Если что-то не работает {#troubleshooting}

**Браузер не открылся.** Откройте `http://localhost:5080` сами или выберите «[[ui:Launcher.Tray.Open]]» в меню значка.

**Сервер не запустился.** Порт 5080 мог занять другой процесс, часто вторая копия TTRPG.Codex. Закройте её и запустите снова. Подробности — в журнале программы запуска («[[ui:Launcher.Tray.Log]]»); отправьте его тому, кто вам помогает.

**Первый запуск медленный.** Это нормально. Следующие запускаются быстро.

**После обновления что-то выглядит странно.** Обновите страницу без кэша (Ctrl+F5 или Cmd+Shift+R на Mac).

Не получилось? [Создайте задачу](https://github.com/myarichuk/TTRPG.Codex/issues) и приложите журнал.
